# Parallel Image Processing System

A Python-based image processing system comparing sequential and parallel execution performance using multiprocessing techniques.

## Features

- Sequential image processing
- Parallel image processing
- Execution time comparison
- Thumbnail generation
- Batch image handling

## Technologies Used

- Python
- multiprocessing
- Pillow (PIL)

## Project Structure

- `sequential_version.py` - Sequential processing implementation
- `parallel_version.py` - Parallel processing implementation
- `images/` - Original image dataset
- `thumbnails/` - Generated thumbnail outputs

## Performance Comparison

The project demonstrates the performance improvement of parallel execution compared to sequential processing.

## How to Run

### Sequential Version

```bash
python sequential_version.py
